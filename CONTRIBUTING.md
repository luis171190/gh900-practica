# Cómo contribuir

GitHub muestra un link a este archivo cuando alguien abre un issue o un PR.
Sirve para decir las reglas de juego antes de que la persona trabaje.

1. Abrí un issue contando qué querés cambiar.
2. Creá una rama desde `main` con el formato `tipo/descripcion-corta` (ej: `docs/arreglo-readme`).
3. Hacé commits chicos con mensajes claros.
4. Abrí un PR y en la descripción poné `Closes #N` con el número del issue.
5. Esperá la revisión del dueño del código (ver `.github/CODEOWNERS`).
